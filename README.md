# 别急着做产品：用 AI 验证你的想法

**给独立开发者和第一次创业的人：先找到值得解决的问题，再决定写多少代码。**

你问：「这个产品你会用吗？」

对方说：「挺好的，做好了告诉我。」

你得到了一句鼓励，还没有得到购买证据。

这个工具包帮你把想法拆成可验证的问题，找到真实使用者，完成一次有用的访谈，再做一个成本可控的实验。AI 用来整理和质疑证据；真实用户、真实行为和真实付款，需要你自己找到。

## 今天就能做的一步

把这句话填完整：

> 我认为【具体人群】在【具体时刻】遇到【问题】，他们现在用【替代办法】解决，付出的代价是【时间／金钱／风险】。我最先要核实的是【尚无证据的假设】。

例如：不要从「给所有自由职业者做财务 AI」开始。先查「同时服务多个客户的独立设计师，最近一次逾期收款怎么处理」。如果没有出现你预想的问题，记录下来；这也是结果。

## 一个小循环，而不是必须照做的七天挑战

1. 写假设：选一个人群、一个场景、一个最危险的未知。
2. 找人：先联系少量符合条件的人，记录拒绝和未回复；不要只访谈支持你的朋友。
3. 问过去：追问最近发生的具体经历、现有办法和代价。
4. 整理证据：分开原话、行为、自述和你的解释，主动找反例。
5. 做实验：在诚实说明产品阶段的前提下，测试一次具体承诺。
6. 做决定：下一步只投入解决当前未知所需的时间和钱。

人数和周期是资源安排，不是市场成立的证明。小样本访谈适合发现问题和机制，不能用来推算整个市场的购买比例。

## 三种容易混淆的信号

| 你听到或看到的 | 可以说明 | 不能直接说明 |
|---|---|---|
| 「我会用」 | 对方表达了兴趣 | 对方会付费或持续使用 |
| 最近为问题花过钱／很多时间 | 问题有可描述的代价 | 你的方案值得换用 |
| 在明确价格和条件下完成试点付款 | 这个客户接受了这次交易 | 大规模需求、长期留存、可盈利获客 |

## AI 的边界

- 不生成假用户、假访谈、假引用来支持结论。
- 原话必须对应笔记编号；找不到就标「缺少证据」。
- 不把 AI 扮演用户当成市场验证。
- 访谈录音先取得同意；上传给 AI 前移除姓名、联系方式及机密业务信息。
- AI 可以建议实验和问题，不能替你观察真实客户的行为。

## 方法来源

工具表和示例是本项目的实操编排，并非以下机构背书。案例全部为教学模拟。

- [Y Combinator：How to Talk to Users](https://www.ycombinator.com/library/6g-how-to-talk-to-users)：学习围绕用户的具体经历提问。
- [Strategyzer：How Strong is Your Innovation Evidence?](https://www.strategyzer.com/library/how-strong-is-your-innovation-evidence)：区分实验产生的不同证据。
- [Strategyzer：A/B Testing and Value Propositions](https://www.strategyzer.com/library/4-simple-steps-to-build-better-value-propositions-with-a-b-testing)：实验指标应对应待验证假设，注册数不能直接替代付费意愿。
